# 기관–시나리오 적합성 정책

## 조사 결론

- 정부조직관리정보시스템은 중앙행정기관 등 정부기구를 제공한다.
- ALIO는 공공기관을 공기업·준정부기관·기타공공기관으로 구분하지만, 이 구분은
  수입 구조와 법적 지정 기준이다. 실제 업무 기능이나 제품 판매 가능성을 뜻하지
  않는다.
- 따라서 `public_corporation` 같은 법적·레이아웃용 대분류를 합성 문서의 의미
  적합성 판단에 재사용하지 않는다.

공식 확인 자료:

- 정부조직관리정보시스템: https://org.go.kr/
- 2026년 공공기관 지정현황: https://job.alio.go.kr/orginfo.do
- 공공기관 유형 설명: https://job.alio.go.kr/information.do

## 구현 원칙

1. 기관의 법적 유형과 실제 업무 기능을 별도 필드로 관리한다.
2. 상업 활동을 전제하는 시나리오는 공식 근거나 명백한 법인·사업 표지가 있을
   때만 허용한다.
3. 새 기관과 미확인 기관에는 `generic_public_body`만 부여한다.
4. 미확인 기관은 일반 행정·조달·인사·보안 시나리오에는 사용할 수 있지만
   제품 출시, 프랜차이즈, M&A, 투자유치, 기술·특허 시나리오에는 쓰지 않는다.
5. 선택한 시나리오에 맞는 기관이 없으면 전체 기관 풀로 되돌아가지 않는다.
   다른 시나리오를 찾고, 모든 조합이 부적합하면 생성을 실패시킨다.
6. 기관별 금지 목록이 아니라 확인된 기능의 허용 목록을 사용한다.

## 현재 확인된 기관

| 기관 | 공식 확인 기능 | 허용 예시 | 금지 예시 |
|---|---|---|---|
| 국립암센터 | 암 연구, 진료, 교육, 홍보, 신기술 개발·보급 | 연구성과, 기술·특허, 의료·연구 | 일반 소비재 출시, 프랜차이즈, M&A |
| 국악방송 | 방송 프로그램 제작·운영, 국악 교육·연구·대중화 | 방송 콘텐츠, 편성, 문화사업 | 스마트 스피커 제조·판매, 특허기술, 프랜차이즈 |

## 신규 기관 처리

신규 기관은 우선 보수적으로 처리한다.

```text
공식 기능 확인됨 → 확인된 기능 태그만 부여
이름에서 강한 근거 확인 → inferred 태그 + 제한적 허용
근거 없음 → generic_public_body만 부여
필수 기능 불일치 → 기관 또는 시나리오 재선택
호환 조합 없음 → 생성 중단
```

이 정책은 이상 문서를 생성한 뒤 제목만 고치는 방식이 아니라, LLM 호출 전에
부적합한 기관–시나리오 조합 자체가 만들어지지 않게 한다.
