# 문서 보안표지와 기관 워터마크 자산

이 디렉터리는 생성 PDF에 넣는 보안 분류표지와 기관 워터마크 원본을 보관한다.
최신 `doc_type`별 생성 파이프라인은 HTML/PDF 렌더가 끝난 뒤
`src/rd2/generators/document_security_marking.py`에서 이 자산을 합성한다.

## 적용 범위

- 기관 워터마크와 보안 분류표지는 `generation_target.classification == "C"`인
  문서에만 적용한다. S와 O 문서에는 적용하지 않는다.
- 한 문서의 모든 페이지에는 같은 기관 자산을 같은 상대 위치로 넣는다.
- 기관 워터마크는 본문 중앙에 작고 옅은 회색으로 넣는다. 보안 분류표지는
  본문과 충돌하지 않는 페이지 가장자리 여백에 별도로 넣는다.
- 입력은 `generated_document.agency_name`을 사용한다. 원본 배치의
  `ordering_agency`만 있으면 렌더 경계에서 `agency_name`으로 한 번 전달한다.
- 외부 입력에서 로고 파일명이나 파일 경로를 받지 않는다. 기관명과 자산의
  연결은 `agency_resolver.AGENCY_LOGO_FILENAMES`만 신뢰한다.
- 매핑에 없는 기관은 기관 워터마크를 생략한다. 알 수 없는 기관에
  `정부부처.png`를 임의로 붙이지 않는다. C 문서의 대외비 분류표지는 그대로
  적용된다.

## PDF 합성 순서

```text
템플릿 HTML/PDF 본문
  -> 투명한 기관 중앙 워터마크
  -> 대외비 또는 군사기밀 분류표지
  -> 최대 10페이지 결과 게시
```

WeasyPrint/Chromium이 만든 PDF는 흰 페이지 배경을 불투명하게 그린다.
따라서 기관 이미지를 `overlay=False`로 본문 뒤에 넣으면 보이지 않는다. 기관
워터마크는 흰 배경을 제거한 저알파 PNG로 바꾼 뒤 `overlay=True`로 합성한다.
이미지 자체가 옅기 때문에 본문 텍스트의 가독성과 텍스트 추출은 유지된다.

기관 워터마크의 승인된 기본값은 다음과 같다.

| 항목 | 값 |
|---|---:|
| 최대 너비 | 페이지 너비의 42% |
| 최대 높이 | 페이지 높이의 30% |
| 세로 위치 | 페이지 중앙에서 아래로 높이의 3.6% |
| 회색 RGB | 82 |
| 최대 알파 | 74/255, 약 29% |
| 선명도 | 대비 1.35, UnsharpMask 1.1/260/2 |

PNG와 SVG 모두 지원한다. SVG는 PDF 삽입 전에 고해상도 PNG로 래스터화한다.
저해상도 PNG도 1,040px 폭으로 확대하고 선명화한 뒤 삽입한다. 흰 픽셀은
투명하게 바꾸되 원본 캔버스의 내부 여백은 자르지 않아, 기관별 문양의 상대
크기를 승인된 미리보기와 동일하게 유지한다.

일반 대외비 표지는 상단 5곳과 하단 5곳, 총 10개 후보 중 모든 페이지에서
본문과 충돌하지 않는 한 위치를 골라 문서 전체에 고정한다. 국방부와
국가정보원의 군사기밀 표지는 각 페이지 상단·하단 중앙의 공통 여백에 넣는다.

## 기관명 매핑

개별 기관 자산은 다음 입력에 사용한다.

| 기준 기관명 | 허용하는 대표 입력 | 자산 |
|---|---|---|
| 감사원 | 감사원 | `감사원.png` |
| 검찰청 | 검찰청, 검찰, 대검찰청, `*지방검찰청`, `*고등검찰청` | `검찰.png` |
| 고위공직자범죄수사처 | 고위공직자범죄수사처, 공수처 | `고위공직자범죄수사처.png` |
| 국방부 | 국방부 | `국방부.png` |
| 국가정보원 | 국가정보원, 국정원 | `국정원.png` |
| 대통령경호처 | 대통령경호처 | `대통령경호처.png` |
| 대통령실 | 대통령실 | `대통령실.svg` |
| 청와대 | 청와대 | `청와대.svg` |

개별 자산이 없는 다음 중앙행정기관은 `정부부처.png`를 공유한다.

```text
정부부처, 기획재정부, 재정경제부, 기획예산처, 교육부,
과학기술정보통신부, 외교부, 통일부, 법무부, 행정안전부,
국가보훈부, 문화체육관광부, 농림축산식품부, 산업통상자원부,
보건복지부, 환경부, 기후에너지환경부, 고용노동부,
여성가족부, 성평등가족부, 국토교통부, 해양수산부,
중소벤처기업부, 인사혁신처, 법제처, 식품의약품안전처
```

기관명 비교에서는 공백과 선택적인 `대한민국` 접두사를 무시한다. 그 밖의
부분 문자열 추측은 하지 않는다.

## 자산 목록과 사용 상태

현재 파일은 17개다. 최신 생성 파이프라인에서 13개를 사용할 수 있고,
4개는 예약 또는 중복 자산이다.

| 파일 | 최신 파이프라인 상태 | 용도 |
|---|---|---|
| `대외비.png` | 사용 | 일반 C 문서 분류표지 |
| `1급_비밀.png` | 사용 | 국방부·국가정보원 1급 분류표지 |
| `2급_비밀.png` | 사용 | 국방부·국가정보원 2급 분류표지 |
| `3급_비밀.png` | 사용 | 국방부·국가정보원 3급 분류표지 |
| `감사원.png` | 사용 | 감사원 기관 워터마크 |
| `검찰.png` | 사용 | 검찰 기관 워터마크 |
| `고위공직자범죄수사처.png` | 사용 | 공수처 기관 워터마크 |
| `국방부.png` | 사용 | 국방부 기관 워터마크 |
| `국정원.png` | 사용 | 국가정보원 기관 워터마크 |
| `대통령경호처.png` | 사용 | 대통령경호처 기관 워터마크 |
| `대통령실.svg` | 사용 | 대통령실 기관 워터마크 |
| `청와대.svg` | 사용 | 청와대 기관 워터마크 |
| `정부부처.png` | 사용 | 매핑된 중앙행정기관 공통 워터마크 |
| `1급_비밀_표지.png` | 예약 | 표지 전용 도안. 현재 페이지 후처리에는 미사용 |
| `2급_비밀_표지.png` | 예약 | 표지 전용 도안. 현재 페이지 후처리에는 미사용 |
| `3급_비밀_표지.png` | 예약 | 표지 전용 도안. 현재 페이지 후처리에는 미사용 |
| `스크린샷 2026-07-16 135023.png` | 중복·미사용 | `고위공직자범죄수사처.png`와 SHA-256이 동일 |

기관 로고 워터마크가 추가되기 전 최신 `doc_type` 파이프라인은 분류표지 4개만
사용했다. 나머지 기관 자산은 `security_mark.py` 기반 구형 파일럿에만 연결돼
있었고, SVG는 그 구형 Pillow 로더가 읽지 못했다. 현재 PDF 후처리는 PNG와
SVG를 모두 지원하므로 위 표의 기관 자산 9개가 모두 실제 매핑 대상이다.

예약·중복 파일은 호환성과 이력 보존을 위해 삭제하지 않는다.

## 결과 메타데이터

성공한 각 PDF의 `manifest.json`에는 기존 `security_marking`과 별도로
`agency_marking`을 기록한다.

```json
{
  "agency_marking": {
    "agency_name": "행정안전부",
    "asset": "logo/정부부처.png",
    "placement": {
      "strategy": "center_watermark",
      "width_ratio": 0.42,
      "max_height_ratio": 0.3,
      "vertical_offset_ratio": 0.036
    },
    "tone": {
      "grayscale": 82,
      "max_alpha": 74
    },
    "overlay": true
  }
}
```

`security_marking`은 대외비 또는 군사기밀 자산과 가장자리 배치 정보를 계속
담는다. 두 필드를 분리해 기관 식별과 보안 등급 표시를 독립적으로 추적한다.
